# Flashcards (Spaced Repetition)

A browser flashcard app: build decks of cards and (in upcoming steps) review them with an SM-2 spaced-repetition scheduler. Plain HTML/CSS/JS, no dependencies, data saved in localStorage.

**Live:** https://lewis-p-t.github.io/flashcards-spaced-repetition/

Run locally: clone and open `index.html`. See `PROGRESS.md` for the build plan.
